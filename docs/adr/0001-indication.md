# ADR 0001: Indication: type 2 diabetes, HbA1c at week 26

- **Status:** Accepted
- **Date:** 2026-11-11
- **Decided by:** Francisco Fernández

## Context

The programme needs one indication shared by all studies. It must produce a repeated continuous endpoint, a natural intercurrent event and a continuous dose-response, and it should draw on the author's pharmacy experience.

## Decision

FJF-2026 is an oral add-on to metformin in adults with inadequately controlled type 2 diabetes. The primary endpoint is change from baseline in HbA1c at week 26 (week 12 in phase II).

## Alternatives considered

Major depression (MADRS): harder missing-data problem but less quantitative safety. Alzheimer's disease: same indication as the CDISC pilot, so the programme would look like the benchmark. Hypertension: simple, but few interesting intercurrent events.

## Consequences

Rescue medication becomes the central intercurrent event, which drives the estimand work. Repeated HbA1c measurements suit MMRM. Hypoglycaemia, renal function and concomitant medication give a meaningful safety profile.
