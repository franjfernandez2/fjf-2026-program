# ADR 0008: Visibility: private until gate 6

- **Status:** Accepted
- **Date:** 2026-11-11
- **Decided by:** Francisco Fernández

## Context

A public repository shows progress but also unfinished work.

## Decision

The repository stays private until gate 6, when the repository, reports, app and website pages are published together.

## Alternatives considered

Public from day one: full history visible. Public from gate 1: progress visible from the first validated case.

## Consequences

Nothing can be shown publicly during the job search before gate 6. If an opportunity arises, the phase III report can be shared as a PDF, or a specific person can be given access. Branch protection is unavailable on private repositories in the free plan, so review is enforced by convention (see CONVENTIONS.md).
