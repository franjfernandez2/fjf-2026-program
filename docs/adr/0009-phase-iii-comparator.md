# ADR 0009: Phase III comparator: placebo added to metformin

- **Status:** Accepted
- **Date:** 2026-11-11
- **Decided by:** Francisco Fernández

## Context

The comparator defines the hypothesis and the primary analysis of FJF-2026-301.

## Decision

FJF-2026 versus placebo, both added to stable metformin. Superiority on the primary endpoint.

## Alternatives considered

Three arms with an active comparator: adds a non-inferiority hypothesis and richer multiplicity, at higher complexity. Active comparator only: needs a justified non-inferiority margin.

## Consequences

Multiplicity covers the primary and key secondary endpoints within one superiority framework.
